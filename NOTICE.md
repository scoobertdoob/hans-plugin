# Notices

## OSRS Toolkit Exporter

Parts of this plugin are adapted from **OSRS Toolkit Exporter**, part of the OSRS Toolkit suite by Gorsokk
(https://github.com/Gorsokk/osrs-toolkit), which is released under the BSD 2-Clause licence.

The adapted portions are the capture and file-format code for `position.json`, `ge_offers.json`, `character.json`,
`quests.json`, `diaries.json`, `combat_achievements.json`, `inventory.json`, `equipment.json`, `bank.json` and
`game_quests.json`, so that Hans writes the same files, in the same formats, as that plugin. Each adapted source
file carries this header:

    // Adapted from OSRS Toolkit Exporter (c) Gorsokk, BSD-2-Clause, https://github.com/Gorsokk/osrs-toolkit

The files are `RsbuddyData.java`, `ToolkitData.java`, `ProgressCaptures.java`, `ItemsCapture.java`,
`PositionCapture.java`, `GeOffersCapture.java`, `GameQuestData.java` and `GameQuestsCapture.java`.
